# Website SPD Radeberger Land

Die Veröffentlichung erfolgt über GitHub Pages unter spdradeberg.de.

1. Dateien aus diesem Ordner (nicht den übergeordneten Ordner) in ein öffentliches GitHub-Repository laden.
2. In Settings > Pages: Deploy from a branch, main, / (root).
3. Unter Custom domain: spdradeberg.de.
4. Bei STRATO vier A-Einträge für @ setzen: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153.
5. Optional www CNAME zu GITHUB-NAME.github.io (konkreter Benutzername benötigt).
6. HTTPS aktivieren und testen. MX/SPF/DKIM/DMARC für das bestehende E-Mail-Postfach niemals verändern.

**Vor Produktivfreigabe wichtig**
- Kontaktformular: FormSubmit an info@spdradeberg.de muss einmalig durch Bestätigungsmail freigeschaltet werden. Bis dahin funktioniert es nicht. Die lokale Rechenaufgabe ist kein verlässlicher Spamfilter.
- Datenverarbeitung: Rechtliche Prüfung des Formularanbieters und Hosting ist erforderlich; im Zweifel Formular bis dahin deaktivieren und nur E-Mail-Link anbieten.
- Betreiberangaben und Nutzungsrechte für alle Fotos von verantwortlicher Person freigeben lassen.
- SEPA-GiroCode mit einer echten Banking-App überprüfen und Empfängernamen bei Bank bestätigen.
- Kabinettsmitglieder aktuell halten und offizielle Links nachprüfen.
